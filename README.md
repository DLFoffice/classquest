# ห้องเรียนผจญภัย (ClassQuest) — เกมตอบคำถามแข่งสดในห้องเรียน

ครูฉายคำถามขึ้นจอ นักเรียนสแกน QR แล้วกดตอบจากมือถือ ระบบนับเวลา ให้คะแนนตามความเร็ว แสดงอันดับสด และบันทึกผลลง Google Sheets

## หน้าเว็บ 3 หน้า
| หน้า | ใช้โดย | ทำอะไร |
|---|---|---|
| `host.html` | ครู (เปิดบนคอมพ์ที่ต่อโปรเจกเตอร์) | แก้ข้อคำถาม → สร้างห้อง → คุมเกม |
| `index.html` | นักเรียน (มือถือ/แท็บเล็ต) | ใส่รหัสห้อง + ชื่อเล่น + เลือกตัวละคร → ตอบ |
| `results.html` | ครู | สรุปผลรายข้อ/รายคน · ดาวน์โหลด CSV · พิมพ์เป็น PDF |

## ลองเล่นทันที (โหมดทดลอง ไม่ต้องตั้งค่า)
เมื่อ `API_URL` ใน `assets/js/config.js` ว่างอยู่ ระบบจะทำงานในเครื่องเดียว:
1. เปิด `host.html` → กด **สร้างห้องเกม**
2. เปิด `index.html` **อีกแท็บในเบราว์เซอร์เดียวกัน** (เปิดหลายแท็บ = นักเรียนหลายคน)
> โหมดทดลองใช้ซ้อมเท่านั้น มือถือนักเรียนจริงต้องเชื่อม Google Apps Script

## ติดตั้งใช้งานจริง
### 1) Google Sheets + Apps Script
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางไฟล์ `gas/Code.gs` ทั้งไฟล์ → บันทึก
3. **การตั้งค่าโครงการ (⚙) → Script Properties → เพิ่ม** `HOST_KEY` = รหัสครูที่ต้องการ (เช่น `teach2026`)
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** → อนุญาตสิทธิ์
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`

ชีตที่ระบบสร้างให้อัตโนมัติ: `ห้องเกม` · `คำตอบรายข้อ` (ทุกคนทุกข้อ) · `สรุปผลผู้เล่น` (อันดับสุดท้าย) · `_state` (ซ่อนไว้ สำรองสถานะเกม ห้ามลบระหว่างเล่น)

### 2) หน้าเว็บ (GitHub Pages)
1. ใส่ URL ใน `assets/js/config.js` → `API_URL: 'https://script.google.com/macros/s/.../exec'`
2. อัปโหลดทุกไฟล์ในโฟลเดอร์ `web/` ขึ้น repository ใหม่ → Settings → Pages → Deploy from branch (main / root)
3. ครูเปิด `https://<ชื่อ>.github.io/<repo>/host.html` · QR บนจอจะพานักเรียนไปหน้าเข้าห้องเอง

## ระหว่างเล่น
- **Space / Enter / → / ปุ่มรีโมตเลื่อนสไลด์** = ไปขั้นต่อไป (เริ่ม → เฉลย → อันดับ → ข้อต่อไป)
- **F** เต็มจอ · **M** เปิด/ปิดเสียง
- เฉลยอัตโนมัติเมื่อหมดเวลา หรือเมื่อนักเรียนตอบครบทุกคน
- คลิกชื่อในห้องรอเพื่อนำออก (ชื่อไม่เหมาะสม)
- นักเรียนเผลอปิดหน้า เปิดใหม่จะกลับเข้าเกมเดิมได้ (แท็บเดิม)

## คะแนน
ตอบถูก = 500 + โบนัสความเร็วสูงสุด 500 (ยิ่งเร็วยิ่งมาก) · ถูกติดกันตั้งแต่ข้อที่ 3 ได้โบนัส +100 · ตอบผิด/ไม่ตอบ = 0

## แก้ข้อคำถาม
- พิมพ์ในหน้าจอครูได้เลย (ระบบจำไว้ในเครื่อง) · รองรับ 4 ตัวเลือก และถูก/ผิด · ตั้งเวลารายข้อ · ใส่คำอธิบายหลังเฉลย
- **วางจาก Excel**: คอลัมน์ `คำถาม | ตัวเลือก1 | ตัวเลือก2 | ตัวเลือก3 | ตัวเลือก4 | ข้อที่ถูก(1–4) | เวลา | คำอธิบาย`
- ชุดตัวอย่างอยู่ใน `assets/js/sample.js`

## รองรับผู้เล่น
ออกแบบสำหรับ 1 ห้องเรียน (แนะนำไม่เกิน ~40 คน, สูงสุด 80) — มือถือถามสถานะทุก ~2 วินาที ผ่าน Apps Script

## สำหรับนักพัฒนา
- ตรรกะเกมอยู่ที่ `web/assets/js/engine.js` (ใช้ร่วมกันทั้งโหมดทดลองและ Apps Script)
- แก้ engine แล้วรัน `./build.sh` เพื่อสร้าง `gas/Code.gs` ใหม่ (รวม `gas/adapter.gs` + engine)
