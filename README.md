# ห้องเรียนผจญภัย (ClassQuest) — เกมตอบคำถามแข่งสดในห้องเรียน

ครูฉายคำถามขึ้นจอ นักเรียนสแกน QR แล้วกดตอบจากมือถือ ระบบนับเวลา ให้คะแนนตามความเร็ว แสดงอันดับสด และบันทึกผลลง Google Sheets

## หน้าเว็บ 3 หน้า
| หน้า | ใช้โดย | ทำอะไร |
|---|---|---|
| `host.html` | ครู (เปิดบนคอมพ์ที่ต่อโปรเจกเตอร์) | แก้ข้อคำถาม → สร้างห้อง → คุมเกม |
| `index.html` | นักเรียน (มือถือ/แท็บเล็ต) | ใส่รหัสห้อง + ชื่อเล่น + เลือกตัวละคร → ตอบ |
| `results.html` | ครู | สรุปผลรายข้อ/รายคน · ดาวน์โหลด CSV · พิมพ์เป็น PDF |

## ลองเล่นทันที (โหมดทดลอง ไม่ต้องตั้งค่า)
เมื่อ `API_URL` ใน `assets/js/config.js` ว่างอยู่ ระบบจะทำงานในเครื่องเดียว:
1. เปิด `host.html` → กด **สร้างห้องเกม**
2. เปิด `index.html` **อีกแท็บในเบราว์เซอร์เดียวกัน** (เปิดหลายแท็บ = นักเรียนหลายคน)
> โหมดทดลองใช้ซ้อมเท่านั้น มือถือนักเรียนจริงต้องเชื่อม Google Apps Script

## ติดตั้งใช้งานจริง
### 1) Google Sheets + Apps Script
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางไฟล์ `gas/Code.gs` ทั้งไฟล์ → บันทึก
3. **การตั้งค่าโครงการ (⚙) → Script Properties → เพิ่ม** `HOST_KEY` = รหัสครูที่ต้องการ (เช่น `teach2026`)
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** → อนุญาตสิทธิ์
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`

ชีตที่ระบบสร้างให้อัตโนมัติ: `ห้องเกม` · `คำตอบรายข้อ` (ทุกคนทุกข้อ) · `สรุปผลผู้เล่น` (อันดับสุดท้าย) · `_state` (ซ่อนไว้ สำรองสถานะเกม ห้ามลบระหว่างเล่น)

### 2) หน้าเว็บ (GitHub Pages)
1. ใส่ URL ใน `assets/js/config.js` → `API_URL: 'https://script.google.com/macros/s/.../exec'`
2. อัปโหลดทุกไฟล์ในโฟลเดอร์ `web/` ขึ้น repository ใหม่ → Settings → Pages → Deploy from branch (main / root)
3. ครูเปิด `https://<ชื่อ>.github.io/<repo>/host.html` · QR บนจอจะพานักเรียนไปหน้าเข้าห้องเอง

## ระหว่างเล่น
- **Space / Enter / → / ปุ่มรีโมตเลื่อนสไลด์** = ไปขั้นต่อไป (เริ่ม → เฉลย → อันดับ → ข้อต่อไป)
- **F** เต็มจอ · **M** เปิด/ปิดเสียง
- เฉลยอัตโนมัติเมื่อหมดเวลา หรือเมื่อนักเรียนตอบครบทุกคน
- คลิกชื่อในห้องรอเพื่อนำออก (ชื่อไม่เหมาะสม)
- นักเรียนเผลอปิดหน้า เปิดใหม่จะกลับเข้าเกมเดิมได้ (แท็บเดิม)

## ฉากและเอฟเฟกต์
เลือกที่ช่อง **ฉากและเอฟเฟกต์** ในหน้าเตรียมภารกิจ (ค่าเริ่มต้น = อัตโนมัติตามคำในชื่อกิจกรรม) — จอครูและมือถือนักเรียนเปลี่ยนตามกัน
| ฉาก | คำที่ระบบจับได้ | เอฟเฟกต์ |
|---|---|---|
| 🪐 อวกาศ | ดาว สุริยะ อวกาศ จันทร์ | พื้นหลังมืด ดาวกะพริบ ดาวตก ดาวเคราะห์โคจรรอบดวงอาทิตย์ |
| 🐠 ใต้ทะเล | ทะเล ปลา น้ำ ฝน วัฏจักร | ฟองอากาศ ปลาว่าย คลื่น แสงส่องใต้น้ำ |
| 🌿 ธรรมชาติ | พืช ต้นไม้ สัตว์ แมลง ป่า | ใบไม้ปลิว ผีเสื้อ ดวงอาทิตย์ เนินหญ้า เมฆลอย |
| 🧪 ห้องทดลอง | สาร เคมี ไฟฟ้า แรง ร่างกาย | อะตอมหมุน อุปกรณ์ทดลองลอย |
| 🔢 คณิตคิดสนุก | คณิต เลข บวก เศษส่วน เรขา | กระดาษกราฟเคลื่อนที่ เครื่องหมายคณิตลอย |
| ✏️ ห้องเรียน | (ค่าเริ่มต้น) | เครื่องเขียนลอย เครื่องบินกระดาษ |

ลูกเล่นระหว่างเกม: แถบสีกวาดเปลี่ยนฉาก · คำถามลอยเข้าทีละคำ · 5 วินาทีสุดท้ายขอบจอเรืองแดง + "หมดเวลา!" · เฉลย: ตัวเลือกผิดพลิกจม ตัวเลือกถูกมีรัศมีหมุนและประกาย · น้องดินสอโผล่มาพูด · อันดับเลื่อนแซงพร้อมตัวเลขวิ่ง · โพเดียมมีสปอตไลต์ มงกุฎ และพลุ · ห้องรอ: นักเรียนส่งอีโมจิลอยขึ้นจอครูได้
> ถ้าเครื่องตั้งค่า "ลดการเคลื่อนไหว" (Reduce motion) ระบบจะปิดเอฟเฟกต์ให้อัตโนมัติ

## ด่านหิมะ + ตารางพันนิตต์ (ชุดพันธุกรรม ม.3)
- ชุดเริ่มต้น: **พันธุกรรม ม.3 · ด่านหิมะของฝูงจิ้งจอก** 10 ข้อ (เปลี่ยนชุดได้ที่ปุ่ม ✨ ชุดตัวอย่าง ▾)
- **เรื่องเล่าเปิดเกม**: พิมพ์ในช่อง 📜 (บรรทัดละ 1 ฉาก) → กดเริ่มเกมแล้วจ่าฝูงจิ้งจอกจะเล่าเรื่องทีละฉาก (Space = ต่อไป)
- **เส้นทางข้ามด่าน**: ข้อไหนทั้งห้องตอบถูก ≥ 50% ขบวนเดินหน้า 1 ด่าน · ต้องผ่าน 60% ของจำนวนข้อเพื่อเปิดประตูน้ำแข็ง · ไม่ผ่าน = พายุหิมะ
- **ตารางพันนิตต์**: ช่อง 🧬 ในการ์ดคำถาม พิมพ์ `Bb x bb | ขนเทา | ขนขาว` (ชื่อลักษณะเด่น | ด้อย ไม่บังคับ) · รองรับ 2 ยีน เช่น `AaBb x AaBb` (ตาราง 4×4)
  - ติ๊ก **แสดงตอนถาม** = โชว์ตารางว่างระหว่างถาม · ไม่ติ๊ก = โชว์เฉพาะตอนเฉลย (ใช้กับข้อที่ตารางจะเฉลยคำตอบ)
  - ตอนเฉลย ระบบเติมช่องทีละช่อง และสรุปอัตราส่วนฟีโนไทป์/จีโนไทป์ให้

## รูปแบบการเล่น 2 โหมด (เลือกก่อนกด "สร้างห้องเกม")
| | 🎮 เล่นสด | 🏃 นักเรียนเล่นเอง |
|---|---|---|
| ใครคุมจังหวะ | ครู (Space / รีโมต) | นักเรียนแต่ละคน |
| เวลา | ทุกคนตอบข้อเดียวกันพร้อมกัน | จับเวลาแยกรายคน (เวลาเริ่มนับเมื่อเปิดข้อ ไม่นับตอนอ่านหน้าเปิดด่าน) |
| เฉลย | ขึ้นจอครู + มือถือ | ขึ้นมือถือทันทีหลังตอบ |
| จอครู | คำถาม เฉลย อันดับ | แดชบอร์ดความคืบหน้ารายคนแบบสด |
| จบเกม | ครบทุกข้อ | ครูกด "🏁 ปิดห้องและประกาศผล" → โพเดียม |

- **การเข้าห้อง**: นักเรียนกรอก **ชื่อ-สกุล** (บันทึกลงชีตและหน้าสรุปผล) + **ชื่อเล่น** (ขึ้นจอ)
- ชีต `คำตอบรายข้อ` และ `สรุปผลผู้เล่น` มีคอลัมน์ **ชื่อ-สกุล** ต่อท้าย (ชีตเดิมจะเพิ่มหัวคอลัมน์ให้เอง)

## 🏕️ โหมดฐาน (แบ่งกลุ่มไปคนละฐาน)
1. หน้าเตรียมภารกิจ → เลือก **🏕️ แบบฐาน** (ระบบเปิด 4 ด่านให้ถ้ายังไม่มี) → เลือกฐานของแต่ละข้อที่ไอคอน 💧🔥🌿🌪️ บนการ์ด
2. ติ๊ก/ไม่ติ๊ก **"ทำครบฐานแล้วให้เลือกฐานอื่นต่อได้"** (หมุนฐาน)
3. สร้างห้อง → จอครูเป็นแดชบอร์ด 4 คอลัมน์ → กด **🖨️ พิมพ์ QR ทุกฐาน** ได้แผ่น A4 มี QR 4 ฐาน (ตัดไปวางแต่ละฐาน)
4. นักเรียนสแกน QR ของฐาน → กรอกชื่อ → เข้าฐานนั้นทันที (สแกน QR รวมจะได้หน้าเลือกฐาน)
5. ทำครบฐาน → เห็นคะแนนฐาน + ฐานที่ผ่านแล้ว → ถ้าหมุนฐานได้ กด "เลือกฐานต่อไป" · คะแนนสะสมรวมในชื่อเดียว
6. ครูกด **🏁 ปิดห้องและประกาศผล** → โพเดียม · ชีตคำตอบมีคอลัมน์ **ด่าน/ฐาน** · หน้าสรุปผลมีป้ายฐานกำกับแต่ละข้อ

## 🖼️ ภาพประกอบโจทย์ (เพิ่มเองภายหลังได้)
- ในการ์ดคำถาม กด **🖼️ เพิ่มภาพประกอบ** → เลือกไฟล์ (ระบบย่อขนาดให้) หรือ **🔗 ใช้ลิงก์ภาพ** (https://)
- ภาพจะถูกเก็บใน Google Drive ของครู โฟลเดอร์ **ClassQuest Images** (แชร์แบบ "ทุกคนที่มีลิงก์ดูได้") — ต้องใส่รหัสครูก่อนอัปโหลด
- ภาพขึ้นทั้งจอครูและมือถือ · คลิก/แตะภาพเพื่อขยายเต็มจอ · เปลี่ยน/ลบภาพได้ตลอด
- ใช้ได้กับทุกชนิดคำถาม (4 ตัวเลือก ถูก/ผิด จับคู่ เติมตาราง)
> ครั้งแรกที่ Deploy เวอร์ชันนี้ Google จะขออนุญาตใช้ Google Drive เพิ่ม — กดอนุญาต

## ภารกิจ 4 ด่านธาตุ + กิจกรรม 4 แบบ
ชุดเริ่มต้น: **พันธุกรรม ม.3 · ภารกิจสี่ธาตุของฝูงจิ้งจอก** (8 ข้อ)
| ด่าน | ฉาก | กิจกรรม |
|---|---|---|
| 💧 ธาราหิมาลัย | หิมะ | 4 ตัวเลือก |
| 🔥 ดวงใจอัคนี | ภูเขาไฟ ลาวา | เติมตารางพันนิตต์ (มีภาพพ่อแม่จิ้งจอก) |
| 🌿 ปฐพีเล่ห์รัก | หุบผา คริสตัล | จับคู่คำศัพท์ |
| 🌪️ วายุภัคมนตรา | ท้องฟ้า สายลม | ดูภาพพ่อแม่ แล้วเติมเซลล์สืบพันธุ์ + ลูกเอง |

- **ชนิดคำถาม** (ปุ่มบนการ์ด): 4 ตัวเลือก · ถูก/ผิด · 🧬 เติมตาราง · 🔗 จับคู่ (2–6 คู่ ฝั่งขวาสลับลำดับให้อัตโนมัติ)
- **เติมตาราง**: พิมพ์การผสม เช่น `Bb x bb | ขนเทา | ขนขาว` + ป้ายใต้ภาพพ่อแม่ · ภาพจิ้งจอกเป็นสีเทา/ขาวตามจีโนไทป์ให้เอง · ติ๊ก "ให้เติมเซลล์สืบพันธุ์เองด้วย" = ขั้นสูง (สลับลำดับ B/b ได้ ระบบตรวจตามที่นักเรียนเติม)
- **คะแนนบางส่วน**: เติมตาราง/จับคู่ ถูกกี่ช่องได้คะแนนตามสัดส่วน (ในชีตบันทึกว่า "ถูกบางส่วน x/y")
- **ด่าน**: เลือกด่านของแต่ละข้อที่ไอคอนบนการ์ด · แก้ชื่อด่านในแผงซ้าย · เข้าด่านใหม่มีฉากเปิดด่าน (Space = เริ่มด่าน)
- **คริสตัลธาตุ**: จบด่านแล้วถ้าทั้งห้องได้คะแนนเฉลี่ย ≥ 50% ได้คริสตัล 1 ชิ้น · ได้ 3 ใน 4 ชิ้น ประตูแห่งพันธุกรรมเปิด

## คะแนน
ตอบถูก = 500 + โบนัสความเร็วสูงสุด 500 (ยิ่งเร็วยิ่งมาก) · ถูกติดกันตั้งแต่ข้อที่ 3 ได้โบนัส +100 · ตอบผิด/ไม่ตอบ = 0

## แก้ข้อคำถาม
- พิมพ์ในหน้าจอครูได้เลย (ระบบจำไว้ในเครื่อง) · รองรับ 4 ตัวเลือก และถูก/ผิด · ตั้งเวลารายข้อ · ใส่คำอธิบายหลังเฉลย
- **วางจาก Excel**: คอลัมน์ `คำถาม | ตัวเลือก1 | ตัวเลือก2 | ตัวเลือก3 | ตัวเลือก4 | ข้อที่ถูก(1–4) | เวลา | คำอธิบาย`
- ชุดตัวอย่างอยู่ใน `assets/js/sample.js`

## รองรับผู้เล่น
ออกแบบสำหรับ 1 ห้องเรียน (แนะนำไม่เกิน ~40 คน, สูงสุด 80) — มือถือถามสถานะทุก ~2 วินาที ผ่าน Apps Script
